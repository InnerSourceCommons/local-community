# InnerSource Commons Portland

Welcome to the Portland, Oregon InnerSource community! This is a local community
for practitioners in the Portland metro area (and the wider Pacific Northwest) who
want to learn, share, and grow InnerSource practices together.

## Getting involved

You become a member of the community the moment you join us — there is nothing
formal to sign up for. :tada:

- Join the InnerSource Commons Slack via the [invite link](https://innersourcecommons.org/slack).
- Say hello in the **#local-portland** channel and introduce yourself.
- Watch this directory and the InnerSource Commons events calendar for upcoming
  local meetups.

## Point of contact

This community is looking for one or more local organizers. If you'd like to help
lead the Portland community, reach out in the
[#local-portland Slack channel](https://innersourcecommons.slack.com/archives/C0B8Q78D5U0).

## Repository work

- Working directory: [Portland](./).
- `materials/` — talks, case studies, and reference material for local events.
- `brand/` — logos and virtual backgrounds for the local community.
- `minutes/` — notes from local meetups and organizer syncs.
- `templates/` — reusable meetup and slide-deck templates.
